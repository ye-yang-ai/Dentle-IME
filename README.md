# 口腔医学输入法

一款面向口腔医学生的安卓输入法项目，旨在让口腔医学学习中的专业术语和生僻字输入更便捷。

## 项目目标

口腔医学学习中会频繁输入专业名词，其中一些字词在通用输入法中不容易找到。本项目计划结合口腔医学词库与用户的输入习惯，逐步优化候选词排序，减少重复查找和选词的时间。

## 计划功能

- 支持口腔医学专业术语和生僻字的输入。
- 根据用户的输入习惯调整候选词排序。
- 提供可持续补充和维护的专业词库。

## 当前状态

已完成可离线使用的拼音候选原型，可构建调试 APK，在安卓系统中启用并切换到 Dental IME。键盘支持拼音 26 键与九宫格切换、拼音组合、中文候选词、中英文切换、英文大小写、数字、常用符号、空格、删除、回车和输入法切换；首页提供输入测试框。键盘左上角的键盘图标可选择拼音布局，选择会在本机保留。26 键输入 `nihao` 或九宫格输入 `64426` 可选择“你好”；九宫格支持单字、词语、口腔术语、连续整句、简拼和全拼混合输入。九键数字码有歧义时，可点击候选上方的拼音项筛选，也可点击“选拼音”逐位指定字母；整句候选上方的分段可以点击改词。26 键的单字母输入显示最多 28 个中文候选，末尾固定为该字母的小写和大写；输入完整拼音时显示离线词库中全部精确匹配的词条，不显示原样英文字母候选。未构成完整拼音时仍可在候选栏末尾选择原样输入。

第一批口腔医学词库收录 525 个术语，按完整拼音输入时优先显示，例如 `yatiyasui`（牙体牙髓）、`genjianzhouyan`（根尖周炎）、`zhongzhiya`（种植牙）。词条见 [`lexicon/dental_terms.txt`](lexicon/dental_terms.txt)，尚待专业审校。

连续输入拼音时，输入法会组合多词候选，例如 `wohaoxiangni` →“我好想你”、`woyaobaya` →“我要拔牙”、`jintianzuolegenguanzhiliao` →“今天做了根管治疗”。也可输入每个字拼音的首字母，例如 `whxn` 查询“我好想你”“我很想你”等简拼候选；全拼音节和首字母还可以混合使用，例如 `woxihn` 查询“我喜欢你”。简拼没有整句词条时，候选栏会提供可用前缀，选择前缀后保留剩余拼音继续选词，例如 `tym` 可选择 `ty` →“太阳”，再用剩余的 `m` →“猫”；`srdr` 可分段选择“虽然”和“但是”。普通词、口腔医学词和会话词组共同参与切分；上下文词组帮助排序。整句候选可点击选择，空格选择首项。键盘上方会分段显示整句草稿；点其中一段可查看该段拼音的同音候选，选词后只替换这一段，再点整句候选或按空格提交。可依次修改多段，纠错选词会参与本机记忆。当前最多处理 120 个连续全拼字母、20 个连续简拼字母或 40 个混拼字母；候选排序仍可能需要手动选择。

点击候选词、按空格或完成分段修改后提交整句，输入法会在本机记住该拼音下的最终选择；全拼选择还会同步记到对应简拼，例如输入 `yangye` 选择“杨烨”后，输入 `yy` 会优先显示“杨烨”。重启后记忆仍保留，可在应用首页点“清除选词记忆”删除。

使用 Android Studio 打开本项目并运行 `app`，然后在应用首页按“启用输入法”进入系统设置，开启 Dental IME。返回应用后按“切换输入法”选择 Dental IME，即可在首页或其他应用的文本框中试用。模拟器连接实体键盘时，需要开启“显示屏幕键盘”才能看到软键盘。

## 隐私原则

选词记忆只在本机保存“拼音、所选候选词、选择次数”，不保存完整输入内容；该文件不参与云备份或设备迁移。可随时在应用首页清除记录。
