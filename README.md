# 口腔医学输入法

一款面向口腔医学生的安卓输入法项目，旨在让口腔医学学习中的专业术语和生僻字输入更便捷。

## 项目目标

口腔医学学习中会频繁输入专业名词，其中一些字词在通用输入法中不容易找到。本项目计划结合口腔医学词库与用户的输入习惯，逐步优化候选词排序，减少重复查找和选词的时间。

## 计划功能

- 支持口腔医学专业术语和生僻字的输入。
- 根据用户的输入习惯调整候选词排序。
- 提供可持续补充和维护的专业词库。

## 当前状态

已完成最小输入法原型，可构建调试 APK，在安卓系统中启用并切换到 Dental IME。当前键盘支持英文大小写、数字、常用符号、空格、删除、回车和输入法切换；首页提供输入测试框。中文拼音、口腔医学词库和选词记忆尚未实现。

使用 Android Studio 打开本项目并运行 `app`，然后在应用首页按“启用输入法”进入系统设置，开启 Dental IME。返回应用后按“切换输入法”选择 Dental IME，即可在首页或其他应用的文本框中试用。模拟器连接实体键盘时，需要开启“显示屏幕键盘”才能看到软键盘。

技术路线、可行性与开发条件见[技术方案与开发条件](docs/技术方案与开发条件.md)。

开发电脑的软件安装与真机调试步骤见[环境配置指南](docs/环境配置指南.md)。

## 隐私原则

输入习惯数据可能包含敏感信息。项目开发时将优先考虑本地处理、数据最小化和用户对记录功能的控制；具体的数据处理方式会在功能实现后说明。
