# 词库来源与许可

`app/src/main/assets/pinyin.db` 是随 APK 发布的离线拼音候选库。生成脚本为 `tools/generate_pinyin_db.py`，从 [jieba 的 `dict.txt`](https://github.com/fxsjy/jieba/blob/master/jieba/dict.txt) 选取词频最高的 120,000 个、长度不超过 6 字的汉字词条，再用 [pypinyin 0.55.0](https://github.com/mozillazg/python-pinyin) 生成无声调拼音。单字的多个读音都收录；多字词按 pypinyin 默认读音转换。原始 `dict.txt` 的 SHA-256 为 `7197C3211DDD98962B036CDF40324D1EA2BFAA12BD028E68FAA70111A88E12A8`。

第一批口腔医学词条在 [`lexicon/dental_terms.txt`](../lexicon/dental_terms.txt)，共 525 条。编写时参考了 jieba、[THUOCL 医学词表](https://github.com/thunlp/THUOCL/blob/master/data/THUOCL_medical.txt) 及 [Cassotis 医学术语目录](https://github.com/shenmin/cassotis-lexicon/blob/master/manifests/medicine_catalogue_terms.tsv)，结合常见口腔医学术语筛选和补充；已排除明显不相关的地名、成语及药品商品名。对上游数据的修改包括筛选、去重、增补术语和重新生成拼音。这份清单是初步人工筛选，尚未由口腔医学专业人员逐条审校。生成脚本将这些词条加入基础库；完整拼音命中时三字及以上专业词优先，双字词适度加权，前缀联想仍按基础词频排序。词库不包含用户输入记录。

连续拼音输入补充使用 Cassotis 的[会话词频表](https://github.com/shenmin/cassotis-lexicon/blob/master/data/generated/dict_conversation_frequency_sc.txt)和[词组转移表](https://github.com/shenmin/cassotis-lexicon/blob/master/data/generated/dict_lm_transition_sc.txt)。项目保存了前者的原始快照 [`conversation_frequency_sc.txt`](../lexicon/conversation_frequency_sc.txt)，SHA-256 为 `77A30C65A7543607E03B32C1867C3D7C6FF1E7DA64C5F673B7E39A784B6699B9`。生成数据库时只取分数不低于 200、长度 2–6 字的纯汉字词组，共 39,857 条，其中约 1.6 万条不在原基础库中。词组转移表的原始文件 SHA-256 为 `3056002E84157E0BB2B7DD8E8DBFEDE03DC0B4EF73BC849E04ADCA9BD721FCA4`；用 `python tools/filter_conversation_transitions.py <dict_lm_transition_sc.txt 的路径>` 筛出两侧都是常见会话词的 94,778 条，保存为 [`conversation_transitions.tsv`](../lexicon/conversation_transitions.tsv)。这些记录用于整句路径评分，不作为单独词条显示。

拼音生成器为包含“出血”的词额外收录 `xue` 读音，因此“牙龈出血”可通过 `yayinchuxue` 输入，同时保留原有读音。整句组合使用现有词条和词组转移分数，不上传输入内容。

Cassotis 采用 CC BY-SA 4.0。`lexicon/dental_terms.txt`、`lexicon/conversation_frequency_sc.txt`、`lexicon/conversation_transitions.tsv` 及其在 `pinyin.db` 中的衍生数据按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 提供；应用代码不受此数据许可约束。jieba、THUOCL 和 pypinyin 的 MIT 许可声明保留如下。

生成后的数据库随应用打包，输入中文不需要联网或另行下载语言包。重新生成时，安装 `pypinyin==0.55.0`，下载上述 jieba `dict.txt`，执行 `python tools/generate_pinyin_db.py <dict.txt 的路径>`。三个 `lexicon` 数据文件已在项目中，无需在普通 Android 构建时下载上游数据。
