## 安装步骤

1. 双击上述安装包，按安装向导完成 Android Studio 安装。安装位置可以使用默认值。
2. 首次启动 Android Studio，按 Setup Wizard 安装推荐的 Android SDK 组件。需要阅读并自行接受显示的许可条款。若向导允许选择组件，现阶段可优先安装 Android SDK、Platform Tools 和 Build Tools；模拟器可暂缓。
3. 在 Android Studio 的 `Tools > SDK Manager` 中检查：`SDK Platforms` 至少有一个稳定版 Android 平台；`SDK Tools` 中安装了 Android SDK Platform-Tools 和 Android SDK Build-Tools。记录页面显示的 Android SDK Location。
4. 不用额外安装 Kotlin、Gradle 或独立 JDK。Android Studio 提供 Kotlin 开发支持，并附带推荐使用的 JetBrains Runtime；项目建立后由 Gradle Wrapper 管理构建版本。[Java 构建说明](https://developer.android.com/build/jdks)
5. 等项目开始集成 Rime 的 C++ 引擎时，再到 `Tools > SDK Manager > SDK Tools` 安装 `NDK (Side by side)` 和 `CMake`，避免现阶段下载暂时用不到的大型组件。[NDK 安装说明](https://developer.android.com/studio/projects/install-ndk)

## 真机调试

1. 在安卓手机的“设置 > 关于手机”中连续点击版本号/构建号，开启开发者选项；不同品牌菜单名称可能略有差异。
2. 在开发者选项中开启 USB 调试，用可传输数据的 USB 线连接电脑，并在手机上确认调试授权提示。
3. Android Studio 应能在设备列表中显示手机。若没有显示，可用 `Tools > Troubleshoot Device Connections` 排查；部分品牌手机在 Windows 上还需要安装厂商 USB 驱动。[官方真机连接指南](https://developer.android.com/studio/run/device) / [厂商驱动列表](https://developer.android.com/studio/run/oem-usb)
4. 连接成功后，在 SDK 的 `platform-tools` 目录执行 `adb devices`，设备状态应为 `device`；若显示 `unauthorized`，检查手机上的授权提示。[ADB 说明](https://developer.android.com/tools/adb)

## 模拟器说明

当前 BIOS 中的虚拟化处于关闭状态，先用真机不会阻碍项目启动。如之后需要使用安卓模拟器，再由电脑使用者进入 BIOS 开启 AMD SVM/虚拟化，并按[官方说明](https://developer.android.com/studio/run/emulator-acceleration)配置 Windows Hypervisor Platform。修改 BIOS 设置前应确认主板对应菜单和现有虚拟化软件的需求。

## 安装后核对

完成安装后，确认 Android Studio 可以启动、SDK Manager 显示已安装平台和 Platform-Tools。连接手机后确认设备可被识别。届时即可在本仓库创建 Kotlin 安卓项目并运行第一个输入法原型。
